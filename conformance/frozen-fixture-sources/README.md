# Frozen-fixture sources

Compiled artifacts that SDK tests load from disk, outside `conformance/tests/`
(own goldens) and `conformance/sdk-output/` (own generator,
`generate-inputs.ts`). They used to be regenerated by hand, so a codegen change
could leave them describing a script the compiler no longer emits. The C=1
binding blob (#187) did exactly that, on top of two earlier codegen changes.

`regenerate.mjs` rebuilds every one of them from the sources below:

```bash
node conformance/frozen-fixture-sources/regenerate.mjs           # rewrite
node conformance/frozen-fixture-sources/regenerate.mjs --check   # rebuild + diff, write nothing
node conformance/frozen-fixture-sources/regenerate.mjs --check --only arraywrite
```

`--check` exits 1 and names the first differing character of each drifted
file. `buildTimestamp` is the only field it ignores. A rewrite keeps the old
timestamp when nothing else changed.

## Toolchains

Every compiler must be built from this checkout:

| tier | build | used for |
|---|---|---|
| TS | `pnpm build` (`packages/runar-compiler/dist`, `packages/runar-sdk/dist`) | TS fixtures, plus `RunarContract.getLockingScript()` for the matches-artifact cases |
| Zig | `cd compilers/zig && zig build` | `packages/runar-zig/src/fixtures/*` except arraywrite |
| Java | `cd conformance/sdk-output/tools/java-driver && gradle fatJar` (builds `compilers/java/build/libs/runar-java-compiler-*.jar`) | `stateful-counter.runar.json` |
| Go | a Go toolchain (`compilers/go` is built into a temp dir on each run) | `raw-output.runar.json` |

Each fixture is rebuilt by the tier that originally produced it. The Zig, Go
and Java fixtures carry that tier's artifact shape (`compilerVersion` suffix,
ANF literal encoding, key set). A TS recompile would change those for reasons
that have nothing to do with the script. Every one of these scripts is
byte-identical to the TS compiler's output for the same source.

Matches-artifact case recipes:

- **fixtures.json:**
  - `codesep-only-honest-deployment` = `getLockingScript()`.
  - `-other-state` = the same with `setState({ log: 'abcdef' })`.
  - `tampered-after-slot` / `-before-slot` flip the code byte 40 bytes after (`7f`→`7e`) or before (`02`→`03`) the codeSep slot.
- **codesep.json:**
  - honest cases = `getLockingScript()` with ctor args `cap0 [0, '']`, `cap5 [5, 'abcd']`, `cap1000 [1000, '']`, `cap2pow200 [2^200 + 7, '00']`.
  - Forged cases replace the codeSep-slot element(s) named in the case's own `why`, then re-patch every `codePartLenSlots` pin by the length change.

## Provenance of the sources

The sources under `examples/` and `conformance/` are referenced in place. The
ones in this directory had no checked-in source before. Each was reconstructed
and accepted only when the TS compiler at the fixture's last freeze commit
reproduced the frozen artifact byte for byte, except `buildTimestamp` and
fields the fixture had already dropped. The freeze commits were:

- `9cc7bf680`: Fund ×2, SatCounter.
- `25095825f`: Tip.
- `eb8b6e082`: ScLen.
- `3138de5da`: InitLog. Its ANF `sourceLoc` / `sourceMap` positions match this file's layout.
- `15b09157f`: TaggedLog. Script, ABI, state fields, constructor/codeSep/code-part-length slots and template digest all match.

Fund, SatCounter, Tip and ScLen follow the inline sources in the SDK tests
that consume these fixtures (`compilers/go/compiler/sighash_codegen_test.go`,
`packages/runar-py/tests/test_sighash_sdk.py`,
`packages/runar-go/sdk_continuation_satoshis_test.go`,
`packages/runar-go/sdk_f024_continuation_amount_test.go`,
`packages/runar-go/sdk_n189_scriptcode_intent_test.go`).

**satcounter (Zig).** `packages/runar-zig/src/sdk_satcounter_continuation_test.zig`
says the fixture is the output of `runar-zig --source SatCounter.runar.zig`. No
`SatCounter.runar.zig` exists in the repo, and none was found in history. The
fixture is built from the TS-syntax `SatCounter.runar.ts` here, through the Zig
compiler (which parses all nine formats). Its script equals the TS output
for the same source. The sourceMap and ANF `sourceLoc` are stripped, as the
test comment says, so no source path or position survives in the artifact.
